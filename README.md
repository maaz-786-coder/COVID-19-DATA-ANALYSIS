# COVID-19-DATA-ANALYSIS

## 📌 Project Overview

This project analyzes COVID-19 case data using Python and popular data analysis and visualization libraries. The goal of the project is to explore the trends, distribution, relationships, and correlations between confirmed, recovered, and deceased COVID-19 cases.

The project includes data exploration and visualization to identify patterns and generate meaningful insights from the dataset.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze how COVID-19 confirmed cases changed over time.
* Identify the highest number of daily confirmed cases.
* Analyze the trend of total deaths over time.
* Analyze the trend of total recoveries over time.
* Study the distribution of daily confirmed cases.
* Detect outliers in confirmed cases.
* Explore the relationship between confirmed cases and deaths.
* Analyze the correlation between confirmed, recovered, and deceased cases.

---

* Python
