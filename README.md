# COVID-19-DATA-ANALYSIS

## 📌 Project Overview

This project analyzes COVID-19 case data using Python and popular data analysis and visualization libraries. The goal of the project is to explore the trends, distribution, relationships, and correlations between confirmed, recovered, and deceased COVID-19 cases.

The project includes data exploration and visualization to identify patterns and generate meaningful insights from the dataset.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze how COVID-19 confirmed cases changed over time.
* Identify the highest number of daily confirmed cases.
* Analyze the trend of total deaths over time.
* Analyze the trend of total recoveries over time.
* Study the distribution of daily confirmed cases.
* Detect outliers in confirmed cases.
* Explore the relationship between confirmed cases and deaths.
* Analyze the correlation between confirmed, recovered, and deceased cases.

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## 📊 Analysis Performed

### 1. Cases Over Time

Analyzed how the number of daily confirmed COVID-19 cases changed over the observed period.

### 2. Highest Daily Confirmed Cases

Identified the date with the highest number of daily confirmed COVID-19 cases.

### 3. Deaths Over Time

Analyzed how the total number of deceased cases changed over time.

### 4. Recoveries Over Time

Analyzed how the total number of recovered cases changed over time.

### 5. Distribution of Daily Confirmed Cases

Visualized the distribution of daily confirmed cases to understand how the case values were spread across the dataset.

### 6. Outlier Detection

Used visualization techniques to identify unusual or extreme values in confirmed COVID-19 cases.

### 7. Relationship Between Confirmed Cases and Deaths

Analyzed the relationship between total confirmed cases and total deceased cases.

### 8. Correlation Analysis

Analyzed the correlation between:

* Total Confirmed and Total Recovered
* Total Confirmed and Total Deceased
* Total Recovered and Total Deceased

---

## 💡 Key Insights

* Daily confirmed cases showed significant changes over the analyzed period.
* Higher numbers of confirmed cases were generally associated with higher numbers of recoveries.
* Total confirmed cases and total deceased cases showed a strong positive relationship.
* The data contained outliers representing unusually high numbers of confirmed cases.
* The correlation analysis showed strong positive relationships between confirmed, recovered, and deceased cases.
